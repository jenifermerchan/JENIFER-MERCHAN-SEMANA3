## Descripción
Proyecto que implementa la gestión de mascotas mediante Programación Tradicional y Orientada a Objetos en Python.

## Reflexión
La diferencia radica en que el desarrollo tradicional se basa en la ejecución secuencial de funciones, el enfoque orientado a objetos modela la realidad mediante clases y propiedades para optimizar la reutilización del código.
